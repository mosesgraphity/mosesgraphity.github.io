Installation (5 minutes, une seule fois)

1

Ajouter l'affichage dans votre scène

Dans OBS, sous Sources, cliquez sur + puis Navigateur. Collez cette adresse :

  • Largeur : 1920 · Hauteur : 1080
  • Placez cette source au-dessus de votre caméra dans la liste.
2

Ajouter la régie dans OBS

Menu Docks › Docks de navigateur personnalisés. Nom : Régie Église, adresse :

Cliquez sur Appliquer : la régie apparaît dans OBS. Vous pouvez la placer où vous voulez.

3

Personnaliser

Dans l'onglet Réglages de la régie : nom de votre église, couleur, style du bandeau, transition. C'est enregistré automatiquement.

Pendant le live

✓
  • Bible : tapez un passage (Jean 3:16, Ps 23:1-4, 1 Co 13) puis Entrée. Choisissez Bandeau ou Plein écran.
  • Suivant ▶ passe au verset suivant directement à l'écran (ou flèche droite du clavier).
  • Bandeau : enregistrez vos pasteurs et orateurs, puis un seul clic pour les afficher.
  • TOUT MASQUER (ou touche Échap) retire tout de l'écran.
La régie doit être ouverte dans OBS (étape 2) pour piloter l'affichage. Une connexion internet est nécessaire pendant le live.
